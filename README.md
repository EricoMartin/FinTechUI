# FinTechUI — Jetpack Compose FinTech UI

FinTechUI is a modern **Jetpack Compose Android application** that showcases clean and elegant **FinTech UI features**, including asset cards, balance visibility toggling, and gradient-styled dashboard components.  
The project focuses on building a beautiful and scalable Compose UI structure that can later be extended with real data and authentication features.

---

## 🚀 Features

- 💳 Dashboard showing estimated total value and portfolio breakdown  
- 👁️ Toggle balance visibility with an eye icon (secured view)  
- 🪙 Asset list using `LazyRow` and `LazyColumn` components  
- 🎨 Modern gradient backgrounds and rounded UI elements  
- ⚡ Built entirely with **Jetpack Compose** and **Material 3**

---

## 🧩 Tech Stack

- **Language:** Kotlin  
- **UI:** Jetpack Compose  
- **Architecture:** Declarative UI (no XML)  
- **Design System:** Material 3  
- **Build Tool:** Gradle (KTS)  
- **IDE:** Android Studio

---

## 🛠️ Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/EricoMartin/FinTechUI.git
   ```

2. Open the project in Android Studio (Giraffe or newer).
3. Sync Gradle and build the project.
4. Run the app on an emulator or a physical device
